# 널스빌리지 SNS 콘텐츠 파이프라인 가이드

> **이 문서는 누구를 위한 건가요?**
> 처음 이 프로젝트를 받은 담당자가 **5분 안에 콘텐츠를 생성**할 수 있도록 씁니다.
> Claude Code만 있으면 됩니다. Python이나 코딩 경험은 없어도 됩니다.

---

## 0. 시작 전 확인사항

**필요한 것 딱 하나: Claude Code**
- Claude Code 설치가 안 되어 있다면 → [claude.ai/code](https://claude.ai/code) 에서 설치
- 설치 후 이 프로젝트 폴더(`[04] 다이버즈`)를 Claude Code에서 열기

**폴더 구조 한눈에 보기**

```
[04] 다이버즈/
├── data/
│   └── nursevillage_content_seeds.csv   ← 여기에 주제를 추가합니다
├── output/
│   ├── commands/                        ← 슬래시 커맨드 정의 파일 (건드리지 마세요)
│   │   ├── generate.md
│   │   ├── review.md
│   │   ├── calendar.md
│   │   └── strategy.md
│   ├── output_content_set.md            ← 발행용 콘텐츠 초안 (여기서 복사해서 씁니다)
│   ├── review_summary.md               ← 검수 결과 요약
│   ├── content_calendar.md             ← 발행 스케줄 + 인수인계 키트
│   └── gen.json                        ← 내부 데이터 (직접 열 필요 없음)
└── decisions.md                         ← 자동 기록되는 의사결정 로그
```

## 1. 새 콘텐츠 만드는 방법 (3단계)

### Step 1 — CSV에 주제 추가

**처음 시작한다면** `data/nursevillage_content_seeds.csv` 파일을 새로 만들고, 헤더 행과 함께 첫 주제를 입력합니다. 헤더 행은 파일당 한 번만 작성하면 됩니다.

```csv
id,topic,tone,target_audience,keywords_required,platform_hint,ref_event
01,번아웃 극복 선배 인터뷰,공감형,경력RN,"번아웃,3교대,프리셉터,태움",뉴스레터,
```

**이후부터는** 같은 파일 맨 아래에 새 행만 이어서 추가하면 됩니다. `/generate`는 매번 전체를 다시 만들지 않고 아직 생성되지 않은 **새 행만** 찾아 처리하므로, 예전에 만든 콘텐츠는 그대로 유지된 채 새로 추가한 시드만 누적됩니다.

**컬럼 작성 규칙**

| 컬럼 | 입력할 수 있는 값 | 비고 |
|------|----------------|------|
| `id` | 숫자 (마지막 번호 + 1) | 중복 안 됨 |
| `tone` | 공감형 / 정보형 / 유머형 | 글의 분위기 |
| `target_audience` | 신규RN / 간호학생 / 경력RN | 독자 설정 |
| `keywords_required` | 쉼표로 구분한 간호 현장 용어 | 모든 채널에 반드시 들어감 |
| `platform_hint` | 카드뉴스 / 카카오 / 뉴스레터 | 참고용 (3종 모두 자동 생성) |
| `ref_event` | 시의성 이벤트명 (없으면 빈칸) | 예: 간호사 국가시험 합격발표 |

---

### Step 2 — `/generate` 실행

Claude Code 채팅창에 입력:

```
/generate
```

그러면 Claude가 자동으로:
1. CSV에서 새 시드를 찾고
2. 카드뉴스(3~5장) + 카카오메시지(200자 이내) + 뉴스레터(600자) 초안을 생성하고
3. `output/output_content_set.md`에 저장합니다

> 새 시드가 없으면 "새 시드 없음. CSV에 주제를 추가하세요."라고 나옵니다.

---

### Step 3 — `/review`로 검수

```
/review
```

생성된 초안이 규격에 맞는지 자동으로 확인합니다.

| 표시 | 의미 | 대응 |
|------|------|------|
| ✅ | 기준 충족 | 그대로 발행 가능 |
| ⚠️ | 권고 사항 | 발행은 되지만 수정 권장 |
| ❌ | 규격 위반 | 수정 후 재생성 필요 |

결과는 `output/review_report.md`에 저장됩니다.

---

## 2. 발행 스케줄 관리

### 새 달 스케줄 만들기

```
/calendar
```

- 미배치 시드가 있으면 다음 달 빈 슬롯 표를 자동으로 추가합니다
- 9월 → 10월 → 11월 순으로 필요한 만큼 계속 추가됩니다
- 날짜는 마케터가 직접 빈 슬롯에 채웁니다

**발행 대기 시드 표**도 함께 생성되어, 아직 날짜를 배치하지 않은 시드를 한눈에 볼 수 있습니다.

---

## 3. 전략 검토 (월말)

```
/strategy
```

seeds 패턴을 분석해 마케터 운영에 유용한 발행 전략안을 생성합니다.
타깃·톤·시의성 분포를 읽어 문제 정의 / 근거 데이터 / 전략 제안 / 우선순위 형식으로 제안합니다.
결과는 `output/strategy_proposals.md`에 저장됩니다.

매달 실행할 필요는 없으며, 전략 재검토가 필요할 때만 실행하면 됩니다.

---

## 4. 슬래시 커맨드 전체 요약

| 커맨드 | 언제 쓰나 | 결과물 |
|--------|----------|--------|
| `/generate` | 새 시드 추가 후 | `output_content_set.md` 업데이트 |
| `/review` | 초안 생성 후 발행 전 | `review_report.md` |
| `/calendar` | 새 시드 추가 후 / 매월 초 | `content_calendar.md` 스케줄 갱신 |
| `/strategy` | 전략 재검토 필요할 때 (월말) | `strategy_proposals.md` |

---

## 5. 검증 규격 (자동 적용)

| 채널 | 규격 |
|------|------|
| 카드뉴스 | 3~5장, 마지막 장에만 CTA |
| 카카오메시지 | 공백 포함 200자 이하 |
| 뉴스레터 | 도입+본문+CTA 합계 550~650자 |
| 현장 용어 | keywords_required 항목이 전 채널에 포함 |

---

## 6. 자주 생기는 상황

| 상황 | 대응 |
|------|------|
| 초안을 어디서 복사하나요? | `output/output_content_set.md`에서 시드 번호로 검색 |
| 특정 시드만 다시 만들고 싶어요 | CSV에서 해당 시드 삭제 후 `/generate` 재실행 |
| 캘린더에 9월 표가 없어요 | CSV에 9월 시드 추가 후 `/calendar` 실행 |
| 글자수가 기준을 벗어났어요 | `/review` 결과에서 해당 시드 확인 → gen.json 수정 후 재생성 |
| 키워드 결측 시드가 있어요 | CSV의 `keywords_required` 칸을 채운 뒤 `/generate` 재실행 |
