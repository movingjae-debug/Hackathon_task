# /review — 생성된 콘텐츠 자가 점검

`output/gen.json`에 저장된 콘텐츠 초안을 읽어 채널별 규격·용어 반영·톤 일치도를 점검하고 결과를 `output/review_report.md`에 저장합니다.

## 실행 순서

1. `data/nursevillage_content_seeds.csv` 읽기 (seeds 메타데이터 확인용)
2. `output/gen.json` 읽기
3. gen.json이 없으면 "gen.json 없음. /generate를 먼저 실행하세요." 출력 후 종료
4. 각 시드마다 아래 3가지 축으로 점검
5. 결과를 `output/review_report.md`에 저장
6. 요약 (통과/주의/실패 건수) 출력

---

## 점검 축

### 1. 포맷 규격 (형식·분량)

| 채널 | 기준 | 판정 |
|------|------|------|
| 카카오메시지 | 공백 포함 200자 이하 | 초과 시 ❌ |
| 뉴스레터 | intro+body+cta 합계 550~650자 | 범위 벗어나면 ❌ |
| 카드뉴스 | 슬라이드 3~5장 | 범위 벗어나면 ❌ |
| 카드뉴스 | 마지막 장만 is_cta: true | 위반 시 ❌ |
| 카드뉴스 | 각 장 헤드라인 + 본문 2~3문장 | 미충족 시 ⚠️ |

### 2. 현장 용어 반영 (keywords_required)

- seeds CSV의 keywords_required에 명시된 단어가 전 채널(카드뉴스·카카오·뉴스레터)에 **1개 이상** 포함되어 있는지 확인
- 포함된 용어 목록을 태그 형식으로 출력: `#프리셉터 #듀티표`
- 한 채널에도 없으면 ❌, 일부 채널 누락 시 ⚠️

### 3. 타깃·톤 일치도

- target_audience(신규RN / 간호학생 / 경력RN)와 tone(공감형 / 정보형 / 유머형)이 실제 텍스트에 드러나는지 확인
- 공감형: 감정 공유·위로 표현 존재 여부
- 정보형: 구체적 수치·절차·팁 존재 여부
- 유머형: 가벼운 어투·이모지·반전 표현 존재 여부
- 타깃 어투(신규RN=응원, 간호학생=안내, 경력RN=동료감) 미반영 시 ⚠️

---

## 판정 기준

| 기호 | 의미 |
|------|------|
| ✅ | 기준 충족 |
| ⚠️ | 권고 사항 (제출은 가능하나 수정 권장) |
| ❌ | 규격 위반 (수정 필요) |

---

## 출력 형식

`output/review_report.md`에 아래 형식으로 저장:

```
# 콘텐츠 검수 리포트

생성일: YYYY-MM-DD | 검수 대상: gen.json (N건)

## 요약
- ✅ 통과: N건
- ⚠️ 주의: N건  
- ❌ 실패: N건

---

## 시드별 상세 결과

### #01 — [토픽명]
| 항목 | 결과 | 비고 |
|------|------|------|
| 카카오 글자수 | ✅ 178자 | |
| 뉴스레터 글자수 | ⚠️ 648자 | 650자 한도 근접 |
| 카드뉴스 장수 | ✅ 4장 | |
| is_cta | ✅ | 마지막 장만 true |
| 현장 용어 | ✅ | #프리셉터 #듀티표 |
| 타깃 일치 | ✅ 신규RN 어투 확인 | |
| 톤 일치 | ✅ 공감형 표현 확인 | |
```

---

## 주의사항

- ❌ 항목이 1개 이상이면 리포트 끝에 **수정 필요 목록** 별도 출력
- gen.json에 없는 시드(seeds에는 있지만 gen.json에 없는)는 "미생성" 으로 표시
- `/generate` 재실행 없이 이 명령만으로 기존 gen.json 전체 재검수 가능
