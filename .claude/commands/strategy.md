# /strategy — seeds 패턴 기반 발행 전략안 자동 생성

seeds CSV를 분석해 마케터 운영에 실질적으로 유용한 발행 전략안 1~2건을 생성하고 `output/strategy_proposals.md`에 저장합니다.

## 실행 순서

1. `data/nursevillage_content_seeds.csv`를 읽는다
2. 아래 3가지 축으로 패턴을 분석한다
3. 전략안 1~2건을 생성해 `output/strategy_proposals.md`에 저장한다

---

## 분석 축

### 타깃 분포 (target_audience)
- 타깃별 시드 수 집계
- 각 타깃의 채널(platform_hint) 분포 확인
- 특정 타깃이 특정 채널에 과도하게 집중되어 있는지 확인
- **단, 해당 포맷과 타깃이 잘 맞는 설계(예: 뉴스레터+경력RN)는 문제로 분류하지 않는다**

### 톤 분포 (tone)
- 톤별 시드 수 집계
- 각 톤의 채널 분포 확인
- 특정 톤이 특정 채널에 고착되어 있는지 확인
- **단, 채널 특성에 맞는 톤 배치(예: 카카오+유머형)는 의도된 설계로 간주한다**

### 시의성 패턴 (ref_event)
- ref_event 보유 시드 수 vs 전체 비율
- 동일 ref_event에 묶인 시드 수 확인
- **발행 순서 전략이 없는 이벤트**를 우선 식별한다

---

## 전략안 양식

각 전략안은 아래 형식으로 작성한다:

```
**전략안 N — [제목]**

> **문제 정의**: 패턴에서 발견된 운영상 공백 또는 기회. 마케터의 시간·일관성 문제와 연결해 서술한다.
> **근거 데이터**: CSV에서 추출한 수치 (타깃/톤/ref_event 분포)
> **전략 제안**: 구체적 콘텐츠 전략 (무엇을, 언제, 어떤 채널에). 시드 번호로 근거를 제시한다.
> **우선순위**: 높음/중간/낮음 + 판단 근거
```

---

## 우선순위 판단 기준

| 등급 | 기준 |
|------|------|
| **높음** | 마케터의 반복 기획 비용을 직접 줄이거나, 유입 피크를 명확히 활용하는 경우 |
| **중간** | 중장기 채널 성장에 영향을 주지만 즉각적 운영 공백은 아닌 경우 |
| **낮음** | 개선 여지는 있지만 현재 운영에 지장 없는 경우 |

---

## 주의사항

- 전략안은 **근거가 확실한 것만** 1~2건 생성한다. 억지로 2건을 채우지 않는다
- "의도된 설계"로 판단되는 패턴은 전략 문제로 분류하지 않는다
- 생성 완료 후 `output/strategy_proposals.md`에 저장하고 요약을 출력한다
