# /calendar — 발행 스케줄 자동 갱신

`data/nursevillage_content_seeds.csv`를 읽어 `output/content_calendar.md`의 **발행 스케줄 섹션만** 갱신합니다.
브랜드보이스 가이드·채널별 성과 기준·CTA 템플릿·비상 상황 대응 섹션은 건드리지 않습니다.

## 실행 순서

1. `data/nursevillage_content_seeds.csv` 읽기
2. `output/content_calendar.md` 읽기
3. 현재 캘린더에서 **이미 날짜가 배치된 시드 ID** 목록 추출
4. 날짜 미배치 시드 파악
5. 미배치 시드가 있으면 → **필요한 월 표를 자동 생성**하여 추가
6. `output/content_calendar.md`의 § 1 발행 스케줄 섹션 재작성
7. 나머지 섹션(§ 2 ~ § 5)은 그대로 유지

---

## 월별 표 자동 생성 규칙

### 언제 새 월 표를 만드는가
- 캘린더의 마지막 월 표가 모두 채워져 있고 미배치 시드가 남아 있으면 → **다음 달 표 자동 추가**
- 미배치 시드 수에 따라 필요한 만큼 월을 계속 추가 (9월 → 10월 → 11월 → 12월 … 순서로)
- 이미 표가 있는 달은 덮어쓰지 않음

### 빈 슬롯 구조
새로 생성하는 월 표는 아래 형식으로 만들고 날짜 칸은 비워둠:

```
### 📅 2026년 N월 발행 계획

| 주차 | 날짜 | 채널 | 시드 # | 주제 | 타깃 | 톤 | 체크 |
|------|------|------|--------|------|------|----|------|
| 1주차 | N/[월] (월) | 카드뉴스 |  |  |  |  | ☐ |
|      | N/[수] (수) | 카카오   |  |  |  |  | ☐ |
|      | N/[금] (금) | 뉴스레터 |  |  |  |  | ☐ |
| 2주차 | ...
| 3주차 | ...
| 4주차 | ...
```

### 채널·요일 고정
- **월 → 카드뉴스 / 수 → 카카오 / 금 → 뉴스레터** 고정

### 날짜 계산
- 해당 월의 첫 번째 월요일부터 시작
- 주 3회(월·수·금) 기준으로 4주치 슬롯 생성

## 발행 대기 시드 표

모든 월 표 아래에 아직 어느 달에도 배치되지 않은 시드 목록을 표시:

```
### 📋 발행 대기 시드 (날짜 미배치)
| 시드 # | 주제 | 채널 힌트 | 타깃 | 톤 | 비고 |
|--------|------|----------|------|----|------|
| #XX    | ...  | 카드뉴스  | 신규RN | 공감형 | ⚡ 시의성: [ref_event명] |
```

- ref_event가 있는 시드에는 `⚡ 시의성` 태그 추가 → 마케터가 우선 배치하도록 유도

---

## 타깃 균형 권고

빈 슬롯에 시드를 배치할 때 주간 타깃 균형 안내 (강제 아님):
- 신규RN / 간호학생 / 경력RN 각 최소 1건/주 권장
- 한 주에 특정 타깃만 있으면 "이번 주 경력RN 없음" 안내 출력

---

## 주의사항

- § 2 브랜드보이스, § 3 성과 기준, § 4 CTA, § 5 비상 상황 섹션은 **절대 수정하지 않음**
- 날짜는 마케터 권한 — 이 커맨드는 **슬롯 구조와 미배치 목록만** 제공
- 실행 완료 후 "추가된 월: N월, 미배치 시드 N건" 요약 출력
